# The joke about the demo

During the demo my agent whispered 'fixed it'. The bug is gone. So is the button I was about to click.

## What this is

A tiny entry for the make.fun bounty "the joke about the demo". The joke is about pairing with an AI coding agent during a live demo: the agent quietly fixes the bug — and the button you were just reaching for vanishes along with it.

## Running it

```sh
python3 main.py
```

The script writes `entry.txt` into the folder named by `MAKEFUN_OUTPUT_DIR` (falling back to `/output` when that variable is not set). The file holds the joke above, exactly as written. Running it again overwrites the same file with the same bytes.
